# READ_RHYTHM - Web 4-Key Rhythm Game

`진짜_최종본임.md` 계획서에 명시된 아키텍처 및 게임 로직을 완벽하게 구현한 4키 웹 리듬게임 프로젝트입니다.

---

## 🎮 주요 특징 및 구현 내용

1. **4키 건반 입력**:
   - `D`, `F`, `J`, `K` 4개의 고정 레인 입력 지원
2. **YouTube 기반 타임 클록 동기화**:
   - Web Audio API를 사용하지 않고 YouTube IFrame Player API의 오디오/비디오 재생 시간(`getCurrentTime()`)을 메인 타임 클록으로 직접 사용하여 시각적·청각적 동기화 구현
3. **엄격한 레이아웃 규칙 (19장 반영)**:
   - **좌측 (10~15% 여백)**: HTML5 Canvas 기반 4레인 채보 및 판정선, 타격 이펙트, 콤보 표시
   - **우측 (10~15% 여백)**:
     - **상단 정보 표시창 (중앙 정렬 세로 3단)**:
       1. `[모드] : [음악 이름]` (예: MASTER : World is mine)
       2. `MAXIMUM COMBO : [숫자]`
       3. `SUCCESSFUL RATING : [비율%]`
     - **하단**: YouTube 영상 및 음원 플레이어
4. **100.00% 만점 정규화 달성률 및 콤보 가중치 (13장 반영)**:
   - 판정 가율: `PERFECT (1.0)`, `GOOD (0.5)`, `FAST (0.3)`, `FAIL (0.0)`
   - 15콤보 이상 연속 성공 시 콤보 배율 **1.2배** 활성화 (FAST/FAIL 시 리셋)
   - 스페셜 노트(노란색) 추가 가중치 반영
   - 총 가점을 ALL PERFECT + FULL COMBO 이론상 최대 가점으로 정규화하여 100.00% 만점 산출
5. **랭크 시스템 (15장 반영)**:
   - S: 95.00% 이상
   - A: 85.00% 이상
   - B: 75.00% 이상
   - C: 65.00% 이상
   - F: 65.00% 미만
6. **4개 난이도 시스템 및 3초 카운트다운 (18장 반영)**:
   - かんたん (Easy - 초록색 `#22c55e`)
   - ふつう (Normal - 주황색 `#f97316`)
   - むずかしい (Hard - 빨간색 `#ef4444`)
   - マスター (Master - 보라색 `#a855f7`)
   - 난이도 선택 시 3초 카운트다운(3, 2, 1) 후 게임 시작
7. **1ms 단위 정밀 싱크 오프셋 설정 (21장, 22장 반영)**:
   - 톱니바퀴 모달을 통해 1ms 단위 싱크 조절 및 `localStorage` 영속 보관
8. **Chart Editor (23장 반영)**:
   - 개발자용 채보 작성기: 유튜브 타임라인 제어, Beat Snap (1/4 ~ 1/32), D/F/J/K 실시간 노트 배치, JSON 가져오기/내보내기

## 🚀 실행 방법

### 방법 1. 즉시 브라우저 실행 (무설치 단독 실행)
Node.js 설치 없이도 즉시 브라우저로 실행할 수 있는 파일이 포함되어 있습니다.
- `read_rhythm/standalone.html` 파일을 Chrome/Edge 등 브라우저로 열면 모든 기능이 즉시 동작합니다.

### 방법 2. Vite 개발 서버 실행
Node.js 환경이 준비되어 있는 경우:
```bash
cd read_rhythm
npm install
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속하여 플레이할 수 있습니다.
